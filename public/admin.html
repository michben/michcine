Sécurité

Le mot de passe par défaut est encore actif. Toute personne connaissant l'adresse de cette page peut modifier votre catalogue et les comptes de vos joueurs. Changez-le maintenant.

Changer le mot de passe d'administration

Le mot de passe est conservé en base sous forme d'empreinte, jamais en clair. Il survit aux redéploiements. Notez-le : il n'existe aucun moyen de le retrouver.

Générateur de code d'entrée VIP

Générez un code d'invitation illimité à distribuer pour contourner le blocage d'inscription.

Créer un compte

Crée directement un compte avec identifiant et mot de passe, sans email à valider. Cochez « compte enfant » pour un compte restreint au mode enfant (uniquement des films pour enfants), avec son propre classement.

Avant d'activer le parrainage

Marquez vos joueurs actuels comme fondateurs : sans cela, ils ne pourront plus entrer dans le jeu une fois le parrainage exigé, faute de code.
